3 — État initial (as-built)

Auto : un élément dont la Date Immersion (onglet Immersion) est ≤ Date de référence est considéré terminé.
Pour un élément en cours, remplir la colonne juste à droite de son ID dans Inputs (C/E/G/I/K/M) : Beton:N, Outfitting, FloatUp, Basin, Parking[:N], Ballast, Done (SPE : Zone:N à la place de Beton/Outfitting). Ajouter :AAAA-MM-JJ en suffixe pour préciser la date de début réelle (sinon = date de référence).
